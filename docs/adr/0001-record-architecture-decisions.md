# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-08-01

In the context of a public personal website with deployment and routing choices that outlive individual code changes, facing the risk that future maintainers reverse those choices without their original context, we decided for short architecture decision records under `docs/adr/` and against relying on commit history alone, to preserve rationale close to the implementation, accepting a small documentation cost for each broad decision.
