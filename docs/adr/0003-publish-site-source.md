# ADR-0003: Publish the website source

- Status: Accepted
- Date: 2026-08-01

In the context of a personal website that also serves as a public example of Kaito Shigyo's work, facing the choice between hiding implementation details and making the site inspectable, we decided for a public GitHub repository and against a private repository, to make the implementation, history, and quality practices accessible, accepting that repository contents must be reviewed before publication.
