# ADR-0004: License code and content separately

- Status: Accepted
- Date: 2026-08-01

In the context of publishing a repository that mixes reusable website code with personal writing and media, facing ambiguity about whether one license grants rights to both, we decided for the MIT License on software and reserved rights on original content and media, to invite code reuse without granting unintended content reuse, accepting an explicit license boundary that contributors must preserve.
